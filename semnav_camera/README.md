# turtlebot-mapping



***


## Name
Semantic Mapping and Navigation using a Turtlebot 4

## Description
The aim of this project will be to develop a system to allow semantic mapping and navigation within an unknown environment. A semantic map provides a geometric representation of an environment that explicitly represents the location and type of individual objects within the environment. Recent developments in the field of robotics have resulted in open source systems which allow such semantic maps to be constructed using a handheld camera. In this project the student will explore the potential for using such a system to map a space and to then allow an agent (e.g. human user or robot), to search for objects and navigate within the environment.
